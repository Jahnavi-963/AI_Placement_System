# 🎓 AI Placement Management System

## 📌 Project Overview

The **AI Placement Management System** is an AI-powered web application developed using Python and Streamlit to help students assess their placement readiness and prepare for campus placements.

The system provides placement prediction, resume analysis, interview practice, skill gap analysis, career recommendations, company eligibility checking, prediction history, and placement report generation in a single platform.

## 🚀 Features

- 🔐 Student Login & Signup
- 👤 Student Profile Management
- 🎯 AI-Based Placement Prediction
- 📄 ATS Resume Analyzer
- 🎤 AI Interview Practice
- 💬 Interview Feedback
- 📈 Skill Gap Analysis
- 💼 Career Recommendation
- 🏢 Company Eligibility Checker
- 📊 Analytics Dashboard
- 📜 Prediction History
- 🏆 Certificate Generation
- 📑 Placement Report PDF

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Frontend:** Streamlit
- **Machine Learning:** Scikit-learn
- **Data Processing:** Pandas
- **Data Visualization:** Plotly
- **AI:** Gemini AI
- **Resume Analysis:** NLP / Text Processing
- **Report Generation:** ReportLab
- **Data Storage:** CSV

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Jahnavi-963/AI_Placement_System.git
```

Open the project folder:

```bash
cd AI_Placement_System
```

Install the required packages:

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Start the Streamlit application using:

```bash
python -m streamlit run app.py
```

The application will open in the browser at:

```text
http://localhost:8501
```

## 🎯 Placement Prediction

The system uses a Machine Learning model to estimate a student's placement probability based on relevant academic and skill-related inputs.

## 📄 ATS Resume Analyzer

Students can upload their resumes and receive ATS-based analysis, including skill matching and resume-related feedback.

## 🎤 AI Interview Practice

The interview module provides mock interview questions and evaluates student answers to help improve interview preparation.

## 📈 Skill Gap Analysis

The system identifies skills that students need to improve based on their career goals and current skill profile.

## 💼 Career Recommendation

Based on the student's skills and profile, the system provides suitable career recommendations.

## 🏢 Company Eligibility

Students can check their eligibility for different companies based on academic criteria and other placement-related requirements.

## 📊 Dashboard

The analytics dashboard provides visual insights into placement predictions and student performance.

## 📑 Placement Report

The system generates a placement report containing relevant student performance and placement information in PDF format.
